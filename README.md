# SparkNest Cleaning Co. 🧹

A modern, responsive website for a professional cleaning service business, built using HTML, CSS, and JavaScript.

## 🌐 Live Website

[View SparkNest Cleaning Co.](https://uditdeveloper.github.io/sparknest-cleaning/)

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Free cleaning quote request form
- Form validation for required fields and email addresses
- Cleaning service selection
- Preferred cleaning date and home size selection
- Additional details field for customer requests
- Make.com webhook integration for form submissions
- Google Sheets integration to store submitted quote requests

## ⚙️ How It Works

1. Customers fill out the quote request form.
2. JavaScript validates the submitted information.
3. The form sends the data to a Make.com webhook.
4. Make.com processes the submission and adds the data to Google Sheets.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Make.com
- Google Sheets
- GitHub Pages

## 🚀 Deployment

The website is hosted using GitHub Pages.

## 🎯 Project Goal

To create a user-friendly cleaning service website with an automated quote request workflow that helps organize customer enquiries efficiently.
